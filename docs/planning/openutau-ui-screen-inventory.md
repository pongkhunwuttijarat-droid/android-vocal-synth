## 2. Primary editor source detail and Web crosswalk

### 2.1 Desktop startup and Welcome (detailed source pass)

#### Startup transition

- **Splash composition:** fixed 400×180, non-resizable, centered, border-only window; centered app icon, theme-sensitive light/dark logotype, indeterminate progress bar. Source: [`SplashWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/SplashWindow.axaml#L5-L27).
- **Startup work:** when the splash opens it initializes tools, singer manager, project/document manager and audio; on failure it shows “Failed to Start OpenUtau” and closes. On success it creates/shows `MainWindow`, sets it as desktop main window, calls `InitProject()`, initializes the loading window, then closes the splash. Source: [`SplashWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/SplashWindow.axaml.cs#L37-L70).
- **Initial document:** `MainWindow` constructs its view model and calls `NewProject()` before startup `InitProject()`. It starts a 15 ms playback-position timer and 30 s autosave timer, restores saved window position/state, and checks for updates. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L59-L112).

#### Welcome state layout and controls

- `MainWindowViewModel.Page` starts at `0`; the view-model comment defines `0: welcome page, 1: tracks page`, and the XAML `Carousel.SelectedIndex` binds to `Page`. Source: [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L47-L62), [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L86-L88).
- Welcome content is a two-column grid with margins `60,50,60,40`: top recovery-warning row, start/action row, then independently scrollable Recent and Template columns. New/Open buttons are 60 px high and show a localized title and description. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L88-L165).
- **Recent:** each list item shows project name and directory, with minimum row height 48 px; a pointer press opens it. In the view-model, recent entries are built from `Preferences.Default.RecentFiles` and sorted by file `LastWriteTime` descending. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L167-L186), [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L31-L44), [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L99-L112).
- **Templates:** each list item shows its name and opens on pointer press; the view-model ensures the Templates folder exists and enumerates `*.ustx` files. The XAML contains no explicit empty-state placeholder for either list; an empty source therefore leaves its list area blank. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L188-L206), [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L99-L112).
- Menu roots remain visible above the carousel. File/Edit/Project roots bind `IsEnabled` to `Page` (disabled at index 0); Tools and Help do not. Opening the menu refreshes recent files, templates, and cache size; closing/leaving restores window focus for keyboard events. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L20-L84), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L256-L268).

#### Entry, actions, and exit behavior

- **Recovery:** `InitProject` checks `Preferences.Default.RecoveryPath`; if it is nonblank and exists, it exposes a warning button containing the localized recovery prompt plus path, then returns. The old automatic Yes/No recovery dialog code is commented out. Clicking the warning calls `OpenProject([RecoveryPath])` and changes to Page 1. Source: [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L162-L203), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1612-L1615).
- **Command-line project:** if there is no valid recovery path and exactly one command-line argument names an existing file, `InitProject` loads it and switches to Page 1. Failure queues a user-facing open-file error notification; the page assignment is after the load and is skipped on exception. Source: [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L191-L203).
- **New:** with `Templates/default.ustx`, it opens that template, then marks it unsaved and clears its file path; otherwise creates a fresh USTX project. If the template load fails it queues an error and falls through to fresh-project creation. New from the button/menu switches to Page 1 after the unsaved-changes decision. Source: [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L205-L221), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L221-L228).
- **Open:** prompts before discarding unsaved work; accepted file types in this path are USTX, VSQX, UST, MIDI, UFDATA and MusicXML. Cancelled/empty file selection keeps the current page; successful load goes to Page 1; errors are logged and shown as a customizable open-file dialog. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L230-L254).
- **Recent/template:** clicking either first asks to save/continue if there are unsaved changes. Recent opens the project path; template opens it, then clears file path and marks the document unsaved. Load failures enqueue an error notification. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1746-L1764), [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L241-L261).
- The shared Yes/No/Cancel prompt means **Yes** awaits Save then continues, **No** continues without saving, and **Cancel** aborts. Window close with unsaved changes is cancelled pending the same prompt; accepted close shuts the detached Piano Roll, then persists window geometry/state and clears the recovery path. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1830-L1868).

#### Crosswalk and evidence limits

- **Clone contrast:** current Web route starts directly in the docked editor; its shell source has no separate Splash/Welcome, recovery, recent-project, or template page. This is a navigation/screen difference, not a conclusion about the Rust project-session contract. The clone map is summarized above and detailed in subsequent panel sections.
- **Text/localization:** visible Welcome strings are `DynamicResource` keys, so their exact language-specific wording depends on runtime resources; this source pass records roles and not English screenshots.
- **Unverified:** no live desktop window was launched. Pixel styling, keyboard focus sequence, exact prompt wording, stale/missing recent-file behavior, and the loading/error timing must be checked in a visual interaction pass.

### 2.2 Main editor (desktop structural and interaction pass)

- **Grid:** columns are `300,* ,24` (track rail, work canvas, vertical scaler); rows allocate timeline header/playback, expanding track canvas, a splitter, a `3*` Piano Roll with view-model min/max heights, progress text and a 4 px progress bar. The Roll row and splitter follow `ShowPianoRoll`. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L210-L221), [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L401-L418).
- **Playback header:** meter and BPM are clickable and open Time Signature / Type In dialogs; adjacent transport has seek-to-start, play/pause, pause, seek-to-end, plus current position in `mm:ss.fff`. The timeline row has a horizontal scrollbar and a bar/beat tick background. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L222-L277), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L120-L145).
- **Track/timeline surface:** `TrackHeaderCanvas` is paired with an aligned track background, `TickBackground`, and `PartsCanvas`; shared `TrackHeight`, `TrackOffset`, `TickWidth`, and `TickOffset` bindings keep the row/tick geometry aligned. A vertical scrollbar and `ViewScaler` adjust the track viewport/height. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L278-L331), [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L408-L410).
- **Part canvas:** parts receive pointer press/move/release, double-tap and wheel handlers. It overlays a playback-range highlight, live play-position line, and selection rectangle. Its context menu has Delete; wave-part-only Go to File/Replace Audio/Transcribe; voice-part-only Rename/Merge/Split/Apply Pitch submenu. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L332-L400).
- **Timeline/header:** timeline canvas receives wheel/pointer/double-tap and supplies a dynamic context menu. A playhead marker sits in the header; part-lane clicks and track-row scrolling are separate surfaces. During waiting-to-render, an overlay reads localized `progress.waitingrendering`; project progress text/bar are at the bottom. Source: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L286-L310), [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L401-L418).
- **Track header:** current control group includes singer, phonemizer and renderer, volume/pan, mute/solo, FX and overflow/settings; detailed desktop behavior follows in the Track Header pass below, with Web gaps crosswalked in section 2.3. Source: [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L103-L239).
- **Entry and clone contrast:** successful New/Open/Recent/Template/Recovery paths select Page 1. The Web clone enters its docked editor directly. It has separate Arrangement, Piano Roll, Expression Lanes and Note Properties docks; desktop places tracks/parts and the embedded Roll in one window grid.
- **Evidence boundary:** source handlers and thresholds for seek/range, part selection/creation/move/resize, pointer release and double-click roll entry are recorded at lines 98–103 below. They have not been exercised live; pixel feedback, focus/keyboard behavior, context-menu runtime enablement and responsive visual states remain unverified.

#### Track Header behavior (desktop source pass)

- Each header is a 300 px-wide user control with avatar, colored track-number badge, name, and optional singer/phonemizer/renderer rows. The actual height is bound to the track canvas; singer/phonemizer/renderer rows appear at track-height thresholds of `3×/4×/5× ViewConstants.TrackHeightDelta`. Hidden rows move to the `⋯` flyout, which also exposes track settings. Selection border uses the track accent color. Source: [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L6-L7), [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L103-L204), [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L70-L86).
- Clicking a header selects that track; Shift selects through the clicked track; Ctrl (Meta on macOS) toggles it in the selection. Track name opens Type In and accepts only nonblank changed names. Source: [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L47-L48), [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L89-L107), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L531-L546).
- **Singer:** button refreshes/opens a menu of recent and favorite singers, grouped banks, install, singer-folder open, optional additional-singer-folder open, and refresh. If the list is empty, a disabled “no singer” item appears. Choosing one applies the singer in an undo group, prefers a saved per-singer phonemizer then singer default, may switch to a compatible renderer, refreshes avatar, adds to the 16-item recent list, saves preferences, and notifies track/Piano Roll refresh. Source: [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L68-L82), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L231-L265), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L290-L396).
- **Phonemizer/renderer:** phonemizers include singer default, recent entries (capped to eight), and a “more” tree grouped by language; choosing one creates and changes the phonemizer in an undo group and persists recency/default preference. Renderer menu lists only renderers supported by the installed singer type. Source: [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L83-L113), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L412-L465).
- **Volume/pan:** volume slider range `−24…+12`, pan `−100…+100`; both disable while the track is muted. Right-clicking a fader resets to zero. Double-clicking the numeric readout opens an inline text field; Enter or focus loss commits a parseable value clamped to its slider range; Escape cancels. Slider/view-model value changes notify the playback mixer. Source: [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L136-L174), [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L145-L208), [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L217-L243), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L122-L158).
- **Mute/solo:** button toggles its state. Mute context actions are Mute, Mute Only, Mute All Others, Unmute All; solo context actions are Solo Only, Solo Additionally, Unsolo All. Solo state can make non-solo tracks effectively muted; the volume slider follows effective `Muted`. Source: [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L206-L233), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L172-L229).
- **Overflow/context actions:** right-click menu has Remove, Move Up/Down, Rename, Track Color, Duplicate, Duplicate Settings, Voice Color Remapping, and Mix FX. Full Duplicate copies settings plus every track part; Duplicate Settings adds a configured track without parts. The FX button opens Mix FX; Track Settings opens only if the track has an installed singer. Source: [`TrackHeader.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml#L234-L261), [`TrackHeader.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Controls/TrackHeader.axaml.cs#L173-L180), [`TrackHeaderViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TrackHeaderViewModel.cs#L507-L616).
- **State boundary:** the legacy reference mixes direct `UTrack` property updates (volume/pan/mute/solo/FX enabled), playback/events notifications, and `DocManager` commands/undo groups for singer, phonemizer, renderer, track identity/order and similar edits. The Web clone must still route authoritative musical/track changes through the Rust session; only header selection/hover, flyout visibility and layout are UI state.

**Pointer, zoom, and part-opening behavior (source-mapped):**

- Timeline left press seeks the play position to the line tick and captures the pointer; holding/moving continues seeking. Right press starts a range selection; it updates after horizontal movement reaches the 5 px threshold and finalizes on release. Timeline double-tap clears the range. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1031-L1084).
- Wheel with no modifier scrolls tracks vertically; Shift swaps axes for horizontal/vertical scrolling; Alt zooms track height; Ctrl (Meta on macOS) zooms the time axis around the pointer. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L32-L33), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1019-L1029), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1289-L1312).
- Parts canvas: Ctrl/Meta+left-drag begins box selection; left-click blank space deselects and may add a part, starting a move immediately. On a part, edge hit zones resize/trim; the top 6 px of a wave part also has fade-in/fade-out handles. Middle-button drag pans. Right-click selects the clicked part if needed, then opens the context menu; right-click blank space deselects. Matching-button release ends the edit gesture. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1086-L1178), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1181-L1222).
- Double-clicking a voice part lazily creates/initializes the Piano Roll (with loading UI), attaches it in-window or uses a detached window according to the saved preference, shows/focuses it, loads that part at the clicked tick, and attaches expressions. The part context menu’s Apply Pitch submenu is populated from wave parts ordered by track and position, or shows a disabled no-source item. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1150-L1167), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1224-L1287).

### 2.3 Arrangement and tracks (desktop/Web source crosswalk)

- **Desktop arrangement surface:** integrated 300 px TrackHeader rail and aligned timeline/parts canvas, not an independent dock. The timeline shows bar/beat ticks, playhead and selected-range overlay; the parts canvas adds playback-range, selection rectangle, and a type-specific context menu (Delete; wave-part Go to File/Replace Audio/Transcribe; voice-part Rename/Merge/Split/Apply Pitch). Source markup: [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L286-L310), [`MainWindow.axaml`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml#L332-L399).
- **Desktop gestures and menus:** left timeline press/drag seeks; right-drag range-selects after 5 px; double-tap clears the range. Ctrl/Meta-left-drag on parts makes a marquee; blank-lane left click deselects and creates a voice part, then begins moving it; part edges resize/trim; the top 6 px of wave parts has fade handles; right-click selects then opens the part menu; right-click blank deselects; middle drag pans. Double-clicking a voice part opens/loads the embedded or detached Piano Roll at the clicked tick. Timeline right-click builds tempo and time-signature actions. Source: [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1031-L1084), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1086-L1222), [`MainWindow.axaml.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/Views/MainWindow.axaml.cs#L1224-L1265), [`MainWindowViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/MainWindowViewModel.cs#L358-L397). Creation duration uses the project time axis to compute four bars and is undo-grouped: [`TracksViewModel.cs`](../../ref-openutau-clean/desktop-ref/OpenUtau/ViewModels/TracksViewModel.cs#L253-L270).
- **Web arrangement layout and drawing:** clone uses a dock panel with a resizable track-card column and Pixi timeline. It draws the ruler/parts, note miniatures and render-derived wave peaks; the horizontal scrollbar/trackpad drives timeline scroll. The track-card column resizes with a localStorage width; zoom buttons step ×/÷1.25 and Fit to 16 measures. Source: [`arrangement-panel.jsx`](../../ui-mock/react-dock/src/openutau/arrangement-panel.jsx#L27-L147), [`arrangement-panel.jsx`](../../ui-mock/react-dock/src/openutau/arrangement-panel.jsx#L327-L429), [`arrangement-panel.jsx`](../../ui-mock/react-dock/src/openutau/arrangement-panel.jsx#L435-L503).
- **Web timeline input — partial:** pointer-down on a part dispatches `part/select`; `clone-state.jsx` updates `activePartId`, and the Piano Roll reads that active part. So selecting a part in Arrangement and switching to the Piano Roll dock already loads it for editing; do not count that basic path as missing. T004 also records a prior browser check where clicking a scrolled part changed the Roll from 0 to 4 notes: [`T004-web-editor-product-flow.md`](../work/tasks/T004-web-editor-product-flow.md#L1015-L1018). Unlike desktop, the Arrangement hit layer itself has no double-click auto-open/focus gesture.
